# Xtreme Stack Classifier 2.4
Studio Marclay — Lightroom Classic + programa Windows.

O único programa com o qual se comunica é o **Lightroom Classic**.

## Download

- [Pacote Windows (EXE + plugin)](https://github.com/Xtremefottos/XtremeStackClassifier/releases/latest)
- Pasta no Drive: [Xtreme Stack Classifier](https://drive.google.com/drive/folders/1Q7EVcZKh09s3tP9DkVzGG7FJJ6Zlv_M-?usp=sharing)

## Instalar

1. Extraia o ZIP do release.
2. Duplo clique em `Xtreme Stack Classifier.exe`.
3. No Classic: Arquivo → Gerenciador de Plug-ins → Adicionar
   a pasta `plugin/XtremeStackClassifier.lrdevplugin`.
4. Primeira vez: Library → Extras de Plug-in → Configurar executável.
5. Selecione fotos → Xtreme Stack Classifier (abrir no Windows).
6. Classifique. Enviar LrC. No Classic: Sincronizar classificações.
